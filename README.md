# tkh-multires

Multi-resolution semantic abstraction over a temporal knowledge hypergraph:
hyperedge-level hierarchical clustering (structure + MiniLM semantics), a
laminar node read-out, hypergraph-native coarsening, cross-snapshot identity
tracking, and an evaluation designed to avoid coherence circularity.

**Start with [`report.md`](report.md)** (method, formal statement, results,
limitations). The full review/correction history is in
`docs/report_review_history.md`; AI assistance is logged in `AI_USAGE.md`.

## Reproduction

```bash
bash reproduce.sh      # ~5 min; regenerates every file in outputs/ except the inputs listed below
```

The script runs, in order: filter-consistency test → T1 (`load_graph.py`) →
T2 for all four cutoffs (`method.py`) → T4 (`hyperedge_collapse.py --all`) →
T3 events (`build_temporal_events.py`) → T3 stability
(`t3_perturbation_real_embeddings.py`) → `sensitivity_diagnostics.py` →
`paper_identity_diagnostic.py` → T6 extrinsic (`extrinsic_eval.py`) → T5
labeller inputs (`prepare_labelling_input.py`) → `assemble_metrics.py` →
`merge_supernodes.py` → `make_figures.py`.

`merge_supernodes.py` must be the **last** writer of the hierarchy files
(re-running `method.py` drops the `super_nodes` block). It refuses to write if
any label was made on a different hierarchy, if the recomputed event log
differs from `temporal_events.json`, or if laminar containment fails.

**Inputs that are not regenerated by `reproduce.sh`:**

- `outputs/semantic_embeddings.npy` + `embedding_edge_order.json`: all-MiniLM-L6-v2 embeddings of the 334 clustering hyperedges. They need huggingface.co access; regenerate with `compute_embeddings_hf.py` or the Space in `hf_space/` (https://huggingface.co/spaces/aysan98/tkh). One file serves every cutoff via subset matching.
- `outputs/labelling_faithfulness_pilot.json`: the LLM labels. The labeller sees only `labelling_input_<year>_level<k>.json → labeller_input`. Drafts are checked and merged with `src/merge_label_draft.py`, e.g. `labels/draft_2026_level1.json`.
- `outputs/lambda_selection_and_null.json`: **legacy** output of `src/temporal_reg.py`. It is kept only for traceability of the λ = 0 decision and is not reproduced by the current pipeline (see `metrics.json → stability.superseded`).

## Outputs

| file | content |
|---|---|
| `outputs/hierarchy_<year>.json` (`hierarchy.json` = 2026) | node assignment + provenance, edge dendrogram levels, and `super_nodes`: `id, level, parent_id, child_ids, member_ids, label, gloss, label_source, faithfulness_verdict, persistent_id` |
| `outputs/temporal_events.json` | level-0 birth / growth / merge / split / dissolution / weak-link log with persistent ids |
| `outputs/metrics.json` | coherence vs null, stability with per-snapshot nulls and Holm p, sensitivity diagnostics, over-claim rate, extrinsic scores, verified vs assumed |
| `outputs/hyperedge_collapse_<year>_level<k>.json` | T4 coarse hypergraph and per-cluster cohesion |
| `outputs/fig_*.png` | static figures used in the report |
